## 📱 Code Examples

### Quick Repository Usage
```kotlin
// Get doctors
lifecycleScope.launch {
    val result = RepositoryFactory.doctorRepository.getDoctors()
    result.onSuccess { doctors ->
        adapter.submitList(doctors)
    }
}

// Book appointment
val result = RepositoryFactory.appointmentRepository.bookAppointment(request)
result.onSuccess { appointment ->
    Toast.makeText(this, "Booked!", Toast.LENGTH_SHORT).show()
}
```

## 🛠️ Development Setup

### 1. Clone Repository
```bash
git clone https://github.com/AKAMPURIRA-ISAAC/mediconnectug
cd android_app
```

### 2. Configure Backend
```kotlin
// In: app/src/main/java/com/healthbridge/network/ApiService.kt

// For local development:
private const val USE_LOCAL_BACKEND = true

// For production:
private const val USE_LOCAL_BACKEND = false
```

### 3. Build & Run
```powershell
# Quick build
.\scripts\quick-build.ps1

# Complete workflow
.\scripts\build-install-run.ps1

# Auto-rebuild on save
.\scripts\auto-build.ps1
```

**Full setup:** [QUICK_START_v2.0.0.md](QUICK_START_v2.0.0.md)
